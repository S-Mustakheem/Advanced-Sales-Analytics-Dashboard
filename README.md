# Advanced-Sales-Analytics-Dashboard:
This project is a professional Advanced Sales Analytics Dashboard developed using Power BI to analyze sales performance, business growth, regional trends, and KPI metrics. The dashboard provides interactive visual insights that help businesses make data-driven decisions efficiently.

# The project demonstrates complete end-to-end Power BI development including:
Data Cleaning using Power Query
Data Modeling
Star Schema Design
DAX Calculations
KPI Reporting
Interactive Dashboard Creation

# ⭐ Features:
Total Sales KPI
YTD (Year-to-Date) Sales Analysis
MTD (Month-to-Date) Sales Analysis
QTD (Quarter-to-Date) Sales Analysis
Average Order Value Calculation
Product-wise Sales Analysis
Region-wise Sales Analysis
Monthly Sales Trend Analysis
Interactive Filters & Slicers
Professional Dashboard Layo
